[Clinic contract](../../src/domain/contact/service.ts)

The background worker uses the same capability check before its authenticated JSON POST to `/contacts`. The manifest grants access to the production API origin. The reported browser fetch error does not identify the installed bundle or response. Compare the affected installed build with local source and capture only method, route, HTTP status and browser error category before any fix.

Terminal failures receive no automatic retry date within the usable timestamp range. Queue accounting alone cannot establish missing-mobile validation, age, later successful delivery, or per-item idempotency. Review the four existing entries using redacted error category, attempt timestamps and existing completion evidence. Preserve the queue and avoid replay.
